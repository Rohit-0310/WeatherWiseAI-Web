# Security policy

No supported-version or patch SLA has been published. Both applications are under development.

Use the [repository Security tab](https://github.com/Rohit-0310/WeatherWiseAI-Web/security) if private vulnerability reporting is enabled. Otherwise contact the repository owner privately to arrange a secure reporting channel. Keep vulnerability details out of public issues and pull requests. Include affected revisions, impact and a redacted reproduction. Never include live credentials.

The browser bundle must contain no secrets. Gemini credentials belong exclusively to the backend. Browser geolocation coordinates are shared with the API when the user requests device location. Avoid attaching personal location data or full console logs to public reports.
